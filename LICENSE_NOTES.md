# Licensing Status

No license grant is included in this archive. The copyright holder must select
an appropriate license and confirm rights to all contributed code before an
open-source release. Public visibility on GitHub is not itself an open-source
license.

Third-party libraries and pretrained weights remain subject to their own
licenses. This archive includes research checkpoints but no third-party library
source. Confirm model and training-data publication rights before redistribution.
Authorship and citation metadata should be supplied by the researchers
once the publication and rights information is confirmed.
